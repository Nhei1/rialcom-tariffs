# Парсер тарифов RialCom

Скрипт собирает интернет-тарифы со страницы
[rialcom.ru/internet_tariffs](https://www.rialcom.ru/internet_tariffs/) — вкладки
«Многоквартирные дома» и «Частные дома и коттеджи» — и сохраняет их в Excel:

| Название тарифа                         | Количество каналов | Скорость доступа | Абонентская плата |
|-----------------------------------------|--------------------|------------------|-------------------|
| РиалКомий-15+                           | null               | 200              | 1000              |
| …                                       | …                  | …                | …                 |
| Комбо Лайт + РиалКом Интернет 100 + ТВ  | 165                | 100              | 649               |
| …                                       | …                  | …                | …                 |
| Дом №5                                  | null               | 150              | 3000              |
| …                                       | …                  | …                | …                 |
| Комбо Лайт + РиалКом Интернет 50 + ТВ_ч | 165                | 50               | 1599              |

## Требования

- Windows 10/11 (на Linux и macOS тоже работает);
- Python 3.10 или новее ([python.org/downloads](https://www.python.org/downloads/));
- [Poetry](https://python-poetry.org/) 2.x — рекомендуемый способ установки зависимостей.

## Установка и запуск через Poetry

1. Установите Poetry (PowerShell):

   ```powershell
   (Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | py -
   ```

   Установщик кладёт `poetry` в `%APPDATA%\Python\Scripts`. Если команда `poetry` не находится,
   добавьте эту папку в `PATH` и перезапустите терминал. Проверка: `poetry --version`.

2. Скачайте проект и установите зависимости:

   ```powershell
   git clone https://github.com/Nhei1/rialcom-tariffs.git
   cd rialcom-tariffs
   poetry install
   ```

3. Запустите парсер:

   ```powershell
   poetry run rialcom-tariffs
   ```

   В текущей папке появится `rialcom_tariffs.xlsx`, а в консоли — сколько тарифов найдено в каждом блоке:

   ```text
   12:00:00 INFO    Загрузка страницы: https://www.rialcom.ru/internet_tariffs/
   12:00:01 INFO    «Многоквартирные дома» / «Интернет», тарифов: 4
   12:00:01 INFO    «Многоквартирные дома» / «Интернет + Интерактивное ТВ», тарифов: 36
   12:00:01 INFO    «Частные дома и коттеджи» / «Интернет», тарифов: 5
   12:00:01 INFO    «Частные дома и коттеджи» / «Интернет + Интерактивное ТВ», тарифов: 36
   12:00:01 INFO    Сохранено тарифов: 81, файл: C:\...\rialcom_tariffs.xlsx
   ```

## Установка без Poetry

Через стандартные `venv` и `pip`, без активации окружения:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install .
.venv\Scripts\rialcom-tariffs
```

`py` — стандартный запускатор Python для Windows. Если его нет (например, Python из Microsoft Store),
используйте `python`.

## Параметры запуска

| Параметр              | По умолчанию                               | Назначение                                     |
|-----------------------|--------------------------------------------|------------------------------------------------|
| `-o`, `--output ПУТЬ` | `rialcom_tariffs.xlsx`                     | куда сохранить Excel-файл                      |
| `--url URL`           | `https://www.rialcom.ru/internet_tariffs/` | адрес страницы тарифов                         |
| `--html ФАЙЛ`         | —                                          | разобрать сохранённую HTML-страницу вместо сайта |
| `-v`, `--verbose`     | —                                          | подробный лог                                  |

Пример: `poetry run rialcom-tariffs -o result\tariffs.xlsx`. Скрипт можно запустить и как модуль:
`poetry run python -m rialcom_tariffs`.

Код возврата `0` — файл сохранён, `1` — ошибка. Это может быть нет сети, изменившаяся структура сайта
или открытый в Excel файл. Причина пишется в лог.

## Как формируются данные

| Блок                                       | Правило                                                                                                                                                    |
|--------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| «Интернет» (обе вкладки)                   | строка таблицы — тариф; скорость переводится в Мбит/с («до 200000 кбит/с» → 200); количество каналов — `null`                                              |
| «Интернет + Интерактивное ТВ»              | каждая ячейка с ценой — отдельный тариф: название «ТВ-пакет + столбец», каналы — число в скобках, скорость — число из заголовка столбца, плата — значение ячейки |
| «Интернет + Интерактивное ТВ», частный сектор | к названию добавляется `_ч`, количество каналов берётся из одноимённого пакета многоквартирных домов (без учёта регистра и пробелов)                    |

Также:

- Заголовки столбцов приводятся к единому виду «РиалКом Интернет N + ТВ», как в примере из ТЗ
  `Комбо Лайт + РиалКом Интернет 50 + ТВ_ч`, хотя на сайте этот столбец частного сектора называется
  «РиалКом Интернет + ТВ Дом 50».
- Сноски-звёздочки удаляются: «Социальный **» → «Социальный», «РиалКом Интернет 150* + ТВ» → «РиалКом Интернет 150 + ТВ».
- Отсутствующее количество каналов записывается строкой `null`, как в образце из ТЗ.
- Закомментированные в HTML ячейки на сайте не видны, поэтому не парсятся.
- Порядок строк повторяет страницу: многоквартирные дома («Интернет», затем «Интернет + ТВ»), потом частные;
  матрица «Интернет + ТВ» обходится по строкам.

## Почему тарифов 81, а не 106

ТЗ допускает, что к дате выполнения число тарифов изменится. На 10.11.2026 на сайте:

| Вкладка / блок                        | В ТЗ    | Сейчас | Причина                                                                                 |
|---------------------------------------|---------|--------|-----------------------------------------------------------------------------------------|
| Многоквартирные дома / Интернет       | 5       | 4      | убран тариф «Кадмий-15»                                                                 |
| Многоквартирные дома / Интернет + ТВ  | 48      | 36     | столбец «РиалКом Интернет 50 + ТВ» закомментирован в HTML и не отображается: 12 пакетов × 3 столбца |
| Частные дома и коттеджи / Интернет    | 5       | 5      | —                                                                                       |
| Частные дома и коттеджи / Интернет + ТВ | 48    | 36     | 12 пакетов × 3 столбца                                                                  |
| **Итого**                             | **106** | **81** |                                                                                         |

Цены по сравнению со скриншотами в ТЗ тоже изменились. Например, «Комбо Лайт + РиалКом Интернет 50 + ТВ_ч» стоил 1579, сейчас стоит 1599.

## Устройство проекта

Сервер отдаёт страницу целиком: содержимое вкладок лишь скрыто стилями. Поэтому хватает `requests` и
`BeautifulSoup`, браузер (Selenium и т. п.) не нужен.

```text
rialcom_tariffs/
├── cli.py         CommandLineApp — аргументы командной строки, лог, коды возврата
├── app.py         TariffScraper — сценарий «загрузить → разобрать → сохранить»
├── sources.py     PageSource (ABC): HttpPageSource — сайт, FilePageSource — файл
├── parser.py      RialcomTariffParser — находит вкладки и блоки на странице
├── blocks.py      BlockParser (ABC): InternetBlockParser, ComboBlockParser; ComboColumn, ChannelCatalog
├── table.py       HtmlTable — HTML-таблица в виде текста
├── values.py      ValueParser — цены, скорости, каналы, сноски
├── exporter.py    ExcelExporter — запись .xlsx через openpyxl
├── models.py      Tariff, Section
└── exceptions.py  TariffParserError и наследники
tests/             тесты pytest; fixtures/ — урезанная копия страницы
```

Как идут данные: `TariffScraper` берёт HTML у `PageSource`. `RialcomTariffParser` находит вкладку
по кнопке аккордеона, а в ней — таблицы по заголовкам блоков. Каждую таблицу разбирает свой
`BlockParser`, а получившийся список `Tariff` сохраняет `ExcelExporter`.

## Тесты и линтер

```powershell
poetry run pytest
poetry run ruff check .
```

Тесты не обращаются к сети, они используют `tests/fixtures/internet_tariffs.html`.

## Зависимости

- `requests`, `urllib3` — загрузка страницы с таймаутом и повторными попытками;
- `beautifulsoup4` — разбор HTML;
- `openpyxl` — запись Excel;
- `pytest`, `ruff` — только для разработки (группа `dev`).
